- `BASE = 1000` (configurable per quiz)
- `time_remaining` = seconds left when submitted (server-measured, not client)
- Fastest correct answer → up to 1000 pts; last-second correct → near 0
- Incorrect or timeout → 0 pts
- Ties broken by: total correct answers → then earlier cumulative answer time

### 3.6 Media Handling
- Images and audio stored in object storage (S3-compatible).
- Host uploads via pre-signed URL.
- Students stream audio via signed CDN URL.

### 3.7 Anti-Cheat / Fairness (basic)
- Server-side timer authority (client timer is cosmetic).
- One answer per student per question (DB unique constraint).
- Answers accepted only while question state = `OPEN`.

## 7. API Surface (High-Level)

### Auth
- `POST /auth/host/register`
- `POST /auth/host/login`
- `POST /session/join` (body: code, display_name) → returns participant token

### Host
- `POST /quizzes` / `GET /quizzes` / `PUT /quizzes/:id` / `DELETE /quizzes/:id`
- `POST /quizzes/:id/questions` (+ media upload URLs)
- `POST /sessions` → create live session (returns code)
- `POST /sessions/:id/start`
- `POST /sessions/:id/next-question`
- `POST /sessions/:id/end`
- `GET /sessions/:id/leaderboard` (live)

### Student
- `GET /sessions/:id/state` → current phase
- `GET /sessions/:id/current-question` → prompt + media + options (no correct flag)
- `POST /sessions/:id/answer` (body: question_id, option_id)

### WebSocket Events
- Server → Client: `session:started`, `question:open`, `question:closed`, `leaderboard:update`, `session:ended`
- Client → Server: `answer:submit` (fallback if REST not used)

## 8. User Flows

### Host Flow
1. Login → Dashboard → Create Quiz
2. Add questions (text + image + audio + options + correct + timer)
3. Launch session → share code
4. Live view = leaderboard + controls only
5. Advance questions → end session → see results

### Student Flow
1. Open link → enter name → lobby
2. Question appears (image + audio) → choose answer before timer
3. See own result → next question
4. Final leaderboard

## 9. Edge Cases
- Student joins mid-session → starts from current question, previous scores = 0
- Student disconnects → can rejoin with same name + session (token-based)
- Host disconnects → session pauses; resumes on reconnect (state in Redis/DB)
- Audio autoplay blocked by browser → show tap-to-play button
- Duplicate answer submission → rejected (409)
- Session code collision → regenerate
